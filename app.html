How to Install Your Signature

  1. Click "Copy Rich Signature" above.
  2. Open Outlook, and go to File > Options > Mail > Signatures.
  3. Click New, give it a name, and click inside the edit box.
  4. Paste using Ctrl+V (or right-click and paste keeping original formatting).
  5. Click OK to save.
  1. Click "Copy Rich Signature" above.
  2. Open Gmail, click the Settings Cog > See all settings.
  3. Scroll down to the Signature section and click Create new.
  4. Paste into the signature text box using Ctrl+V.
  5. Scroll to the bottom of Gmail settings and click Save Changes.
  1. Click "Copy Rich Signature" above.
  2. Go to Outlook Web Mail, click the Settings Gear > View all Outlook settings.
  3. Go to Mail > Compose and reply > Email signature.
  4. Paste into the editor box using Ctrl+V.
  5. Click Save.
  1. Click "Copy Rich Signature" above.
  2. Open Apple Mail, and go to Mail > Settings > Signatures.
  3. Select your email account, click the "+" button to add a new signature.
  4. Uncheck the option "Always match my default message font".
  5. Clear any default text and paste using Cmd+V.
